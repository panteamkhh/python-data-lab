# Changelog

All notable changes to **Python Data Lab** are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-14

### Added

- **Three tracks, 15 sessions total:** NumPy, Pandas, and Matplotlib.
  - NumPy: foundations, reshaping/indexing, Boolean/broadcasting, vectorized math & grayscale, random sampling & file I/O.
  - Pandas: Series/DataFrames, indexing/filtering, cleaning, groupby/merging, time series & I/O.
  - Matplotlib: Figure/Axes, plot types, subplots/annotations, styling/colormaps, data storytelling.
- **Per session:** theory `README.md`, runnable `notebook.ipynb`, graded `exercises.md`, worked `exercises_solutions.ipynb`, and an `ai-learning.md` guide.
- **Mini projects** in every session (15 total), all self-contained with inline data.
- **One-page cheat sheet per track.**
- Root `README.md`, `requirements.txt`, MIT `LICENSE`, and `.gitignore`.
