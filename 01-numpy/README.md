> **The foundation of the whole stack.** NumPy's `ndarray` is the data structure that pandas, matplotlib, scikit-learn, and every deep-learning framework are built on. Learn it first, and everything after it becomes easier.

---

## 🎯 What this track covers

Five sessions that take you from "what is an array?" to a real image-processing pipeline and a reproducible data-persistence workflow — with views vs. copies, broadcasting, and vectorization explained properly along the way.

---

## 📚 Sessions

| # | Session | Core topics | Mini project |
|:-:|---|---|---|
| **01** | [Foundations & `ndarray`](./session-01-numpy-foundations-and-ndarray/README.md) | Install, dtypes, `array`/`zeros`/`empty`/`arange`/`linspace`, `ndim`/`size`/`shape` | 🔍 Array attribute inspector |
| **02** | [Reshaping & Indexing](./session-02-reshaping-and-indexing/README.md) | `reshape`/`ravel`/`flatten`, views vs. copies, 1D/2D slicing | ✂️ Matrix cropper |
| **03** | [Boolean, Ops & Broadcasting](./session-03-boolean-indexing-operations-broadcasting/README.md) | Boolean masks, AND/OR operators, element-wise vs. `@`, broadcasting | 🎯 Grade filter & curve |
| **04** | [Vectorized Math & Grayscale](./session-04-math-functions-and-grayscale-project/README.md) | `sqrt`/`power`/`sin`/`log`, `np.emath`, image pipeline | 🖼️ Grayscale + B/W threshold |
| **05** | [Random Sampling & File I/O](./session-05-random-sampling-and-file-io/README.md) | Distributions, seeds, `.npz`, `.csv`, dtype caveats | 📡 Simulate & persist a dataset |

## 🧭 How to use this track

Each session has the same five files:

- `README.md` — theory (intuition → formal → code)
- `notebook.ipynb` — runnable **Build It** + **Experiment** cells
- `exercises.md` — 5 graded exercises + a mini project
- `exercises_solutions.ipynb` — full worked solutions
- `ai-learning.md` — prompts to learn the session with an AI assistant

**Recommended flow:** read the README → run the notebook → attempt the exercises → compare with the solutions → build the mini project.
