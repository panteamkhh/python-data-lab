# Security Policy

## Scope

This repository contains educational notebooks and documentation only. It does not
ship a service or handle user data.

## Supported versions

The `main` branch is the only supported version.

## Reporting a vulnerability

If you find a security issue — for example, unsafe code in a notebook that could harm
a learner who runs it — please **do not open a public issue**. Instead, report it
privately:

- Open a [private security advisory](https://github.com/panteamkhh/python-data-lab/security/advisories/new), **or**
- Contact the maintainer via the email on their GitHub profile.

Please include:

- the affected file and cell,
- what happens when it is run,
- and a suggested fix if you have one.

You can expect an initial response within a few days. Thank you for keeping learners safe.
